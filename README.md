# S3 Watch — เฟิร์มแวร์ v0.2.1

นาฬิกา + เครื่องบันทึกเสียง บน **Waveshare ESP32-S3-Touch-AMOLED-2.06**
เขียนตามสเปกที่ล็อกไว้ในเอกสาร `s3 watch.docx`

โค้ดอยู่ใน `S3Watch/` — เปิดไฟล์ `S3Watch/S3Watch.ino` ด้วย Arduino IDE ได้เลย
(ไฟล์เดียวจบ ~2,150 บรรทัด — ไม่ต้องมีไฟล์ .h/.cpp แยกในโฟลเดอร์เดียวกัน)

ถ้าอยากดูแบบแยกไฟล์ตามโมดูล (อ่านง่ายกว่าตอนแก้โค้ด) มีสำรองไว้ที่ `S3Watch_modular/`
เป็นโค้ดเนื้อหาเดียวกันทุกบรรทัด แค่จัดไฟล์คนละแบบ — **แก้ไฟล์ไหนก็ได้ แต่คนละชุดกัน
อย่าลืมเอาการแก้ไปใส่อีกชุดด้วยถ้าจะใช้ทั้งคู่ต่อ**

## โครงสร้างไฟล์

```
Smartwatch S3/
├── README.md
├── S3Watch/                  ← ใช้ตัวนี้แฟลชขึ้นบอร์ดจริง
│   └── S3Watch.ino           ไฟล์เดียว ~2,150 บรรทัด รวมทุกโมดูล
└── S3Watch_modular/          ← สำรอง เนื้อหาเดียวกัน แยกไฟล์ให้อ่าน/แก้ง่าย
    └── S3Watch/
        ├── S3Watch.ino       setup/loop, ปุ่ม, การเลือกโหมดหลับ
        ├── config.h          พิน + ค่าเริ่มต้น + สวิตช์คอมไพล์  ← แก้ที่นี่เป็นหลัก
        ├── settings.h/.cpp   โหลด/เซฟค่าตั้ง (SD + NVS)
        ├── hw.h/.cpp         จอ, RTC, IMU, SD, PMU, I2C helper
        ├── display_1px.h/.cpp หน้าปัดเส้น 1 พิกเซล
        ├── imu_wake.h/.cpp   QMI8658 Wake-on-Motion + ตรวจหงายข้อมือ
        ├── touch.h/.cpp      จอสัมผัส + ตีความท่าทางปัด
        ├── power.h/.cpp      DEEP / LIGHT / ACTIVE + การปลุก
        ├── audio_codec.h/.cpp ES7210 / ES8311 (เลือกได้ใน Settings)
        ├── audio_rec.h/.cpp  I2S DMA → ริง PSRAM → ไฟล์ WAV บน SD
        ├── ui_menu.h/.cpp    เมนู Settings (ตรรกะชุดเดียว วาดได้ 2 แบบ)
        ├── ota.h/.cpp        WiFi + ตรวจเวอร์ชัน + อัปเดตเฟิร์มแวร์
        └── modules.h/.cpp    จุดเสียบฟีเจอร์ใหม่ในอนาคต
```

ทั้งสองชุดคอมไพล์ได้อิสระจากกัน — `S3Watch.ino` เดี่ยว ๆ ไม่มีไฟล์ .h/.cpp ข้าง ๆ เลย
(ถ้าเอาไฟล์จาก `S3Watch_modular/` ไปวางปนกับไฟล์เดี่ยวในโฟลเดอร์เดียวกัน จะคอมไพล์ไม่ผ่าน
เพราะมีฟังก์ชันชื่อซ้ำกัน — อย่าผสมสองชุดนี้ในโฟลเดอร์เดียว)

ภายใน `S3Watch.ino` เดี่ยว จัดลำดับเป็น 4 ช่วง (มีคอมเมนต์คั่นบอกไว้ทุกช่วง):
ค่าคงที่ (เดิมคือ config.h) → ส่วนประกาศฟังก์ชัน/struct ของทุกโมดูล →
ส่วนเขียนจริงของทุกโมดูล (เรียงตามชื่อไฟล์เดิม) → `setup()`/`loop()`

## การตั้งค่า Arduino IDE

* Board: **ESP32S3 Dev Module**
* PSRAM: **OPI PSRAM** ← ถ้าไม่เปิด ริงบัฟเฟอร์เสียงจะจองไม่ได้
* Flash Size: **32MB** (128Mb)
* Partition Scheme: เลือกแบบที่มี **OTA 2 พาร์ทิชัน** (เช่น `16M Flash (3MB APP/9.9MB FATFS)`)
* USB CDC On Boot: **Enabled**

ไลบรารีที่ต้องติดตั้ง

| ไลบรารี | ใช้ทำอะไร |
|---|---|
| **GFX Library for Arduino** (moononournation) | ขับจอ CO5300 ผ่าน QSPI |
| **SensorLib** (Lewis He) | QMI8658 + PCF85063 |
| **lvgl** 9.x | เฉพาะเมื่อ `USE_LVGL 1` |
| ESP_I2S, SD, WiFi, Update, Preferences | มากับ ESP32 core 3.x แล้ว |

### ถ้าคอมไพล์ไม่ผ่านเพราะ LVGL

เปิด `config.h` แล้วเปลี่ยนบรรทัดเดียว:

```c
#define USE_LVGL 0
```

เมนูจะวาดด้วย Arduino_GFX แทน — ปุ่ม เมนู ท่าทาง เหมือนกันทุกอย่าง

ถ้าจะใช้ LVGL จริง ต้องมี `lv_conf.h` อยู่ข้าง ๆ โฟลเดอร์ `lvgl` ใน `libraries/`
(คัดลอกจาก `lvgl/lv_conf_template.h` แล้วแก้)

```c
#define LV_CONF_INCLUDE_SIMPLE 1
#define LV_COLOR_DEPTH   16
#define LV_USE_STDLIB_MALLOC  LV_STDLIB_CLIB
#define LV_FONT_MONTSERRAT_16 1
#define LV_TICK_CUSTOM   0      /* โค้ดนี้ใช้ lv_tick_set_cb() เอง */
```

## ไฟล์บน SD card

### `/settings.cfg` — สร้างอัตโนมัติครั้งแรก แก้ด้วย Notepad ได้

```ini
faceMode=0          # 0 = อนาล็อก, 1 = ดิจิทัล
brightHigh=90       # ความสว่างตอนหงายข้อมือ (%)
brightDim=25        # ความสว่างปกติ (%)
brightHoldMs=10000  # สว่างค้างกี่ ms
wristWake=1         # 0 = ปิดหงายข้อมือ → ใช้ deep sleep
faceAngleDeg=15
faceHoldMs=200
womMg=150
micChip=0           # 0 = ES7210, 1 = ES8311
sampleRate=16000
flushPct=20         # เขียนลง SD เมื่อริงว่างเหลือน้อยกว่านี้
ringMB=4
wifiEnabled=0
wifiSsid=ชื่อไวไฟ
wifiPass=รหัสผ่าน
otaUrl=https://raw.githubusercontent.com/<user>/<repo>/main/firmware.txt
otaToken=                # GitHub PAT (github_pat_...) — ตองเฉพาะ repo private; ทิ้งว่าง = repo public
tzMinutes=420
cpuMhz=80
```

SSID / รหัสผ่าน / OTA URL แก้ในไฟล์นี้ (พิมพ์ตัวอักษรบนจอด้วยการปัดยังไม่ได้ทำ)

### `/rec/YYYYMMDD_HHMMSS.wav` — ไฟล์เสียง

WAV 16-bit mono ตาม `sampleRate` — header ถูกอัปเดตทุกครั้งที่ flush
ถ้าแบตหมดกลางทาง ไฟล์ยังเปิดฟังได้ถึงจุด flush ล่าสุด

## ไฟล์ manifest สำหรับ OTA (วางบน GitHub)

`firmware.txt` — ข้อความธรรมดา 2 บรรทัด:

```
version=0.2.1
url=https://github.com/<user>/<repo>/releases/download/v0.2.1/S3Watch.bin
```

ไฟล์ `.bin` ได้จาก Arduino IDE → **Sketch → Export Compiled Binary**
เครื่องจะอัปเดตเฉพาะตอนกด `Check update` ในเมนู แล้วปิด WiFi ทันทีที่เสร็จ

**repo private (v0.2.1+):** ใส่ `otaToken=` ใน `/settings.cfg` — ใช้ GitHub PAT
(scope `public_repo` ก็พอ สำหรับ repo private ของตัวเอง) เครื่องจะส่ง header
`Authorization: token <PAT>` ตอนอ่าน manifest + ดาวน์โหลด .bin
⚠️ PAT จะเก็บเป็น plain text บน SD/NVS → อย่าใซ้ PAT ท่ีมี scope กว้างเกิน

## โหมดพลังงาน — เลือกเองอัตโนมัติ

| เงื่อนไข | โหมด | ปลุกด้วย |
|---|---|---|
| ปิด `wristWake` + ไม่อัดเสียง | **DEEP** | timer ต้นนาที, ปุ่ม BOOT |
| เปิด `wristWake` + ไม่อัดเสียง | **LIGHT** | timer, IMU INT, แตะจอ, ปุ่ม |
| กำลังอัดเสียง | **ACTIVE** | ไม่หลับ (I2S ต้องมี clock ต่อเนื่อง) |

ข้อจำกัดที่ต้องรู้:

* ขา TP_INT เป็น **GPIO38 ซึ่งไม่ใช่ขา RTC** → ในโหมด DEEP **แตะจอไม่ปลุกเครื่อง** ใช้ปุ่ม BOOT แทน
* โหมด DEEP ตื่นทุกนาทีแล้วบูตใหม่ → ต้องวาดหน้าปัดใหม่ทั้งจอทุกครั้ง
  ในทางปฏิบัติ **LIGHT sleep มักประหยัดกว่า** ที่คาบ 60 วินาที ควรวัดกระแสจริงเทียบกันก่อนเลือก
* ขณะอัดเสียงจะไม่หลับเลย — แบตหมดเร็วกว่าปกติมาก (ตามที่วิเคราะห์ไว้ในเอกสาร)

## เส้นทางข้อมูลเสียง

```
ไมค์ → I2S DMA → บัฟเฟอร์ SRAM 8 KB → ริงบัฟเฟอร์ PSRAM (4 MB)
                                          │
                        ใช้ไปเกิน 80% ────┘ → เขียนลง SD ทีละ 32 KB
                                                จนเหลือ ~25% แล้วหยุด
```

* ตัวอ่าน I2S อยู่ core 0, ตัวเขียน SD อยู่ core 1 → ระหว่างเขียนก้อนใหญ่เสียงไม่ขาด
* ริง 4 MB ที่ 16 kHz mono = เสียงประมาณ **130 วินาที** → flush ครั้งแรกหลังอัดราว 100 วินาที
* กินพื้นที่ ~115 MB/ชม. ตัดไฟล์ใหม่เมื่อถึง ~1.5 GB

## ⚠️ สิ่งที่ยังไม่ได้ทดสอบกับบอร์ดจริง

รายการนี้คือจุดที่ต้องเช็กเมื่อได้ลองแฟลชจริง

1. **ลำดับพารามิเตอร์ของ `Arduino_CO5300`** ต่างกันตามเวอร์ชัน Arduino_GFX
   ถ้าภาพเลื่อน → ปรับ `LCD_COL_OFF` ใน `config.h` (ค่าเริ่มต้น 22)
2. **AXP2101** — โค้ดแค่ตรวจว่ามีอยู่ ไม่ได้แตะรางไฟ
   ถ้าจอไม่ติดเลย ให้ลองคอมไพล์ด้วย `-DPMU_FORCE_RAILS=1` หรือแก้ใน `hw.cpp`
3. **API ของ SensorLib** (`getDateTime`, `configWakeOnMotion`) เปลี่ยนตามเวอร์ชัน
   ถ้าคอมไพล์ไม่ผ่านตรงนี้ บอกได้เลย จะปรับให้ตรงเวอร์ชันที่ติดตั้ง
4. **ชุดรีจิสเตอร์ ES7210 / ES8311** เรียบเรียงจาก driver ของ Espressif — ยังไม่ยืนยัน
   ถ้าอัดแล้วเงียบ ให้สลับ `micChip` ในเมนู (โค้ดตรวจ I2C ให้อัตโนมัติด้วย)
5. **ทิศแกน Z ของ IMU** — ถ้าหงายแล้วจอไม่สว่าง ให้เปลี่ยน `FACE_SIGN` เป็น `-1.0f`
   ใน `imu_wake.cpp` ; ถ้าขยับแล้วไม่ตื่น ให้เปลี่ยน `IMU_INT_SEL` เป็น `INTERRUPT_PIN_2`
6. **ที่อยู่ I2C ของจอสัมผัส** ตั้งไว้ 0x38 (FT3168/FT6336) — ถ้าปัดแล้วไม่มีอะไรเกิดขึ้น
   ให้สแกนบัส I2C ดูก่อน
7. ตั้ง `DEBUG_NO_SLEEP 1` ใน `config.h` ระหว่างดีบัก เพราะ USB Serial จะหลุดเมื่อเครื่องหลับ

## ยังไม่ได้ทำ (เก็บไว้เฟสถัดไป)

* พิมพ์ SSID / รหัสผ่าน / URL บนจอ (ตอนนี้แก้ผ่านไฟล์บน SD)
* เมนูย่อยหลายชั้น — ตอนนี้เป็นรายการเดียวเลื่อนยาว
* ตัวอักษรไทยบนจอ (ฟอนต์เริ่มต้นของทั้ง Arduino_GFX และ LVGL ไม่มีอักษรไทย)
* อ่านเปอร์เซ็นต์แบตจาก AXP2101
* ฟีเจอร์อนาคต: n-lang, RD4 event, ดัชนี 8 มิติ, Whisper STT → เสียบผ่าน `MODULES[]`
